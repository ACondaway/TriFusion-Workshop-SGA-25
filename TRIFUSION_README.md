# TriFusion Workshop@SIGGRAPH Asia 2025

## About This Website

This website has been customized from the [Carpentries Workshop Template](https://github.com/carpentries/workshop-template) to serve as the official site for the **TriFusion Workshop** at SIGGRAPH Asia 2025.

### Theme: Embodied Intelligence Across Humans 😐, Avatars 🫥, and Humanoid Robotics 🤖

This workshop explores the fascinating intersection of computer graphics, artificial intelligence, robotics, and cognitive science, focusing on the seamless transfer of intelligence across different embodied forms.

## How to Use This Template

### 1. Local Development
```bash
# Install dependencies
bundle install

# Serve locally
make serve

# Check configuration
make workshop-check
```

### 2. Updating Workshop Information
Edit these key sections in `index.md`:
- Workshop dates and venue details
- Instructor and helper lists
- Contact information

### 3. Customizing the Schedule
Modify `_includes/trifusion-schedule.html`:
- Update time slots
- Change session titles
- Add/remove activities

### 4. Visual Customization
Edit `assets/css/trifusion-custom.scss`:
- Adjust color scheme
- Modify layout styling
- Update gradient effects
